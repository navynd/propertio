Property deals (inquiryCategory="property")
GET /agents/inquiries → agents/inquirysController.listInquiries
GET /agents/inquiries/:id → agents/inquirysController.getInquiryById
POST /agents/inquiries/:id/close-deal → agents/inquirysController.closeDeal (writes inquiry.dealClosed)
GET /agency/inquiries → agency/inquirysController.listInquiries
GET /agency/inquiries/:id → agency/inquirysController.getInquiryById
POST /agency/inquiries/:id/close-deal → agency/inquirysController.closeDeal (writes inquiry.dealClosed)
Project deals / project leads (inquiryCategory="project")
GET /agents/project-leads → agents/projectInquirysController.listProjectLeads (filters by dealClosed.isClosed)
GET /agents/project-leads/:id → agents/projectInquirysController.getProjectLeadById (returns dealClosed details)
POST /agents/project-leads/:id/submit-deal → agents/projectInquirysController.submitDeal (sets dealApproval.isWaiting, not dealClosed)
POST /agents/project-leads/close-deal-document → agents/projectInquirysController.uploadCloseDealDocument
DELETE /agents/project-leads/:id → agents/projectInquirysController.deleteProjectLead (checks dealClosed?.isClosed before releasing unit)
Agency-side:
GET /agency/project-leads → agency/projectInquirysController.listProjectLeads (filters by dealClosed.isClosed)
GET /agency/project-leads/:id → agency/projectInquirysController.getProjectLeadById (returns dealClosed details)
POST /agency/project-leads/:id/submit-deal → agency/projectInquirysController.submitDeal (sets dealApproval.isWaiting)
POST /agency/project-leads/:id/approve-deal → agency/projectInquirysController.approveDeal (writes inquiry.dealClosed and closes the ProjectUnit)
POST /agency/project-leads/close-deal-document → agency/projectInquirysController.uploadCloseDealDocument
DELETE /agency/project-leads/:id → agency/projectInquirysController.deleteProjectLead (won’t release unit if dealClosed.isClosed === true)
